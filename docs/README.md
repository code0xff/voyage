# docs

Things that are known and not done, and designs for things not built yet.

The code carries its own reasoning — why a constant has the value it has, why an
approach was chosen — and the README carries what the simulator *is*. This
folder is for the third kind: **what is wrong or missing, why it is still that
way, and what it would take.**

The point is that a limitation someone has already investigated should not have
to be investigated again. Every entry here records what was measured, not only
what was concluded.
